# Products

Each product has its versions in its own folder. These are copies, added so a product is easy to open.

Nothing was removed. The original apps are still in `projects/`. GitHub Pages still serves those original builds from `docs/`.

| Product | Versions |
|---|---|
| [Paymie](paymie/versions) | original, linear, claude, codex, header studies, light |
| [MonRize](monrize/versions) | merchants studies |
| [Sellfyi](sellfyi/versions) | selling options |
| [BRICK](brick/versions) | estimates review app. The rest of BRICK stays in `masum-p/brick-needs-work-redesigns` |
| [Halal Lab](halal-lab/versions) | mega-menu study only. The agency website is `hugeicons/halallab-portfolio` |
| [Organization settings](organization-settings/versions) | cards, creative, dark |
| [Objectives](objectives/versions) | dark |

Payper and Leel.Data After V.2 pages stay in the private repo `masum-p/approved-redesign-v02`. That repo was not changed.

Open a version and run the React app:

```sh
npm install
npm run dev
```

The page to edit is the `.jsx` file. `index.html` only starts the app.
